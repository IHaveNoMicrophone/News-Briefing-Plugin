# 新闻速览（浏览器插件）

Chrome / Edge（Manifest V3）新闻速览插件：所有网页右侧显示可拖动的“新闻速览”悬浮球，点击在新标签页打开速览页；顶部是 7 个默认新闻源按钮（可自定义增删），下方“一键总结热点新闻”按钮会抓取各新闻源首页的文章链接，结合**百度实时热搜**的真实热度排序选出最热的 X 条，交给 AI（OpenAI 兼容协议）生成精炼摘要与原文链接。

## 安装

1. 打开 Chrome / Edge，进入扩展管理页（地址栏输入 `chrome://extensions` 或 `edge://extensions`）。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录（`新闻速览插件`）。
4. 插件加载后，浏览器右上角出现图标，所有网页右侧出现红色“新闻速览”悬浮球。

## 使用

- **悬浮球**：点击打开速览页；按住可沿右侧上下拖动，位置自动保存。
- **新闻源按钮**：点击跳转对应网站；在设置里可增删、改名、改网址。
- **一键总结**：先在设置中填写 AI 接口信息，再点击大按钮。插件会并行抓取各新闻源首页（每源超时 12 秒）与百度实时热搜榜，用标题相似度把各源文章与热榜条目匹配，按热度排序取前 X 条，AI 只负责为选中条目写摘要；命中热榜的结果会显示 🔥 热度徽标。若设置了时间范围，超过范围的新闻会自动过滤。
- **时间范围**：设置中可选“全部时间 / 今天 / 近7天 / 近30天 / 近一年 / 自定义”，自定义可填写开始与截止日期；发布时间通过文章 URL、链接周边时间文本识别，无法识别时间的文章会排在末尾。
- **缓存与强制刷新**：新闻源首页与热榜结果会本地缓存 10 分钟（浏览器重启后自动清空），重复点击秒出；点击“强制刷新”可忽略缓存重新抓取。
- **设置**：速览页右上角齿轮按钮。可配置 API Key、Base URL、模型名、总结条数 X（1–30）、新闻源列表、时间范围、悬浮球位置。

## AI 接口

支持任意 OpenAI 兼容协议接口，在设置中填写：

- API Key
- Base URL，例如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1`、`http://localhost:11434/v1`（Ollama）
- 模型名，例如 `gpt-4o-mini`、`deepseek-chat`、`qwen-plus`、`glm-4-flash`

插件会把 `Base URL + /chat/completions` 作为调用地址。

## 权限说明

- `storage`：本地保存设置（API Key 以明文保存在浏览器本地）。
- 7 个默认新闻源域名：用于抓取首页内容。
- `https://top.baidu.com/*`：抓取百度实时热搜榜作为热度排序信号。
- 自定义新闻源和 AI 接口域名：首次一键总结时通过 `chrome.permissions.request` 弹出授权框，授权后才能抓取/调用。可在扩展管理页的“权限”中随时撤销。

## 常见问题

- **某个新闻源显示“抓取失败/超时”**：该网站可能较慢或临时拦截了自动抓取，不影响其他来源，可稍后重试。
- **AI 返回错误**：检查 API Key、Base URL、模型名是否正确，以及该接口是否真的兼容 OpenAI 协议。
- **提示需要配置 API Key**：点击右上角齿轮填写 AI 接口信息并保存。
- **自定义来源无法抓取**：一键总结时浏览器会弹授权框，需点击“允许”；若之前拒绝过，可在扩展管理页“权限”中重新授予。
